# Diversity metrics

## Why this file exists

The evaluation harness has to compare conditions. "More diverse" is not a single number. The papers in this set use four different measures, and they disagree about which one is fairest. This file records what each measure does and what it costs.

## 1. Embedding cosine diversity

Used by Verbalized Sampling and Artificial Hivemind.

```
diversity = 1 − mean pairwise cosine similarity(embeddings)
```

Details:

- VS uses OpenAI text-embedding-3-small, clips negative similarities to 0, and reports a percentage.
- Hivemind uses the same embedding family and reports average pairwise similarity directly.
- Both compute over a pool of responses to the same prompt.

Strengths: cheap, well understood, comparable across papers. Weaknesses: sensitive to phrasing, not meaning. The persona study argues that embedding measures overstate the human–LLM diversity gap by roughly 2 to 3 times because human ideas vary in wording while LLM ideas share phrasing.

## 2. Vendi Score

Used by CreativeDC.

Given a set of embeddings, build the cosine similarity matrix, compute its eigenvalues, normalize them into a probability distribution, and take the exponential of the Shannon entropy.

```
Vendi = exp(−Σ λ_i log λ_i)
```

Range: 1 when all items are identical, up to N when all items are dissimilar. It behaves like an effective number of distinct items.

Strengths: interpretable as a count, not a distance. Weaknesses: depends on the embedding model, and it is not comparable across corpora with different N.

## 3. Novelty against a consensus set

Used by IDEAFix.

```
novelty(idea) = distance(idea, nearest idea in the control-generated set)
```

The control set is the ideas generated by the two control prompts on the neutral brief. That set is the "common knowledge" baseline. Rarity uses a wider reference set: all ideas generated by the model across prompts for the task.

Strengths: directly measures departure from the typical answer, which is the plugin's goal. Weaknesses: the baseline is only as good as the control prompts, and it is model-specific.

## 4. Category metrics

Used by the persona study.

Each idea is labelled on three dimensions: industry context, psychological need, and product form. The taxonomy has 28 categories (9 + 9 + 10).

Metrics:

- Accumulated categories: unique categories covered by the idea pool.
- Accumulated category combinations: unique three-way combinations.
- Average pairwise distance: mean number of dimensions on which two ideas differ, maximum 3.0.

The authors prefer these because categories capture meaning, not phrasing. They report that the main pattern replicates under embedding measures, but the embedding gap between humans and LLMs is 2 to 3 times larger.

## 5. Duplicate rate

The fraction of candidates whose similarity to an earlier candidate or a stored idea is at or above the threshold. This is an engineering metric, not a research one. It is useful for comparing conditions: a condition that produces many paraphrases has a high duplicate rate even if its embedding diversity looks high.

## 6. Usefulness

No paper in this set provides a validated usefulness rubric for open-ended ideas. The evaluation harness uses a five-criterion LLM judge rubric (feasibility, specificity, insight, actionability, evidence) with at least two judges and a manual spot check. The rubric is an engineering construct. The novelty-judge evidence warns that judge scores are unstable, so the harness reports agreement and the raw scores, not only a mean.

## What the evaluation harness reports

For each condition and task:

- mean and standard deviation of embedding diversity,
- mean and standard deviation of novelty against the plain-prompt consensus set,
- duplicate rate,
- usefulness mean, per-judge means, and inter-judge correlation,
- number of runs and the number of ideas per run,
- bootstrap confidence intervals for the difference against plain prompting.

It does not report a single composite score. A condition that wins on diversity and loses on usefulness is reported as such.

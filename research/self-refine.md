# Self-Refine

## What it is

Generate an initial output, ask the same model for feedback, refine with that feedback, and repeat. No training and no external verifier.

## Mechanism

The feedback step externalizes the evaluation. Specific, actionable feedback gives the refinement step a target. Generic feedback does not.

## Experimental setup

| Item | Value |
|---|---|
| Tasks | Code optimization, code readability, sentiment reversal, dialogue response generation, acronym generation, constrained generation, math reasoning |
| Models | GPT-3.5, ChatGPT, GPT-4; Codex for code tasks |
| Feedback | Task-specific, generated by the same model |
| Refinement | Same model, iterative |
| Metrics | Task metrics, automatic preference, human A/B |
| Human A/B | 150 examples per dataset; judges blind to method |

## Exact numbers

- About 20% absolute average improvement across the seven tasks.
- GPT-4 code optimization: 27.3% → 36.0% (+8.7 absolute).
- Dialogue response preference: 25.4% → 74.6% (+49.2).
- Math reasoning gains were modest. ChatGPT's feedback was "everything looks good" for 94% of instances.
- Feedback quality ablation (ChatGPT for code and sentiment, GPT-3.5 for acronyms):

| Task | Specific feedback | Generic feedback | No feedback |
|---|---|---|---|
| Code optimization | 27.5 | 26.0 | 24.8 |
| Sentiment reversal | 43.2 | 31.2 | 0 |
| Acronym generation | 56.4 | 54.0 | 48.0 |

- Iteration gains: code optimization 22.0 → 28.8; sentiment reversal 33.9 → 36.8; constrained generation 29.0 → 49.7. Gains diminish with more iterations.
- With an external signal that identifies an incorrect math answer, gains exceed 5%.

## Known limitations and conflicting results

- The feedback can be generic, and the gain shrinks or disappears.
- The model can rationalize a bad output.
- Math reasoning is the weak case. The model cannot reliably identify a subtle error.
- Huang et al. (2024) show that intrinsic self-correction without external feedback often degrades reasoning. The improvement in some earlier work came from oracle labels or a sub-optimal initial prompt.
- The evaluation is task-specific; "20% average" is not a universal effect.

## Relevance to the plugin

The critique phase is a Self-Refine-shaped loop applied to ideas. It uses an explicit four-criterion rubric and requires a concrete defect. It keeps the original when the critique is generic. It does not critique reasoning chains.
